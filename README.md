# CTL_TOOL

## INTRODUCTION

### CTL is a Linux based tool which combines the Command Line Interface(CLI) with a light-weight C library for file handling.This tool allows programmers and users to perform various file operations like writing , reading , copy , concatenation and other operations without directly using low-level APIs for file  handling.                                The tool is specifically designed for Linux system. The basic version of CTL provides core operation including writing , reading , copy one or multiple file , concatenation , merging and some error handling.The tool supports text and binary files.The content of text file is represented in normal text while the binary content is rep.
